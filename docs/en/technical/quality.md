# Tests, CI and versions

## Tests

- **Rust**: unit tests in sibling files (`src/foo.rs` declares `#[cfg(test)] mod tests;` → `src/foo/tests.rs`), integration tests in `tests/` (real server, real database), fixtures generated by `shiori-testkit`; `cargo clippy -D warnings`, `cargo fmt`.
- **Web**: Vitest + Testing Library (jsdom), oxlint, type checking at build.
- **End to end**: Playwright in Chromium against a debug `shiori serve` on a generated library: page-by-page reading invariant in each mode, resume, next volume, full journey, metadata, PWA and offline, screenshots at four sizes (390×844, 800×1280, 1280×800, 1440×900).
- **Coverage**: at least **80% of lines and branches**, Rust (`cargo-llvm-cov`, pinned nightly) and web (Vitest v8), measured on production code; CI fails below.

## CI

- `.github/workflows/ci.yml`: format, clippy and tests on Linux, Windows and macOS; coverage; front-end build and tests; end to end; dependency audit.
- `docs.yml`: builds this documentation and publishes it on GitHub Pages at each merge into `main`.
- `release.yml` (on a `v*` tag): front end built once, Linux x86_64 and aarch64 binaries (musl, static), Windows x86_64, macOS aarch64 (unsigned); each binary is run and its version compared to the tag; archives and `SHA256SUMS`; `distroless/static:nonroot` Docker image amd64 + arm64 tried then pushed to `ghcr.io/befa160/shiori`. A suffixed tag (`v0.1.0-rc.1`) is a pre-release.

## Versions

Always the **latest stable versions**: stable Rust (`backend/rust-toolchain.toml`), current Node.js (`.node-version`), latest crates, npm packages and GitHub Actions (pinned by SHA). Dependabot opens a grouped PR per ecosystem each week (cargo, npm, actions), one per major version. The only exceptions, pinned on purpose: the coverage nightly and `cargo-llvm-cov`.
